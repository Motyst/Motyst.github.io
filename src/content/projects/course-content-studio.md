A cognitive training course has a lot of moving parts: teaching scripts, lesson slides, artwork and marketing posts, all changing through round after round of revisions. The practical questions were: which version do we record, which visuals are approved, and was a rejection about the idea or how it was executed? This studio answers them in one place.

It runs locally and keeps everything in plain HTML, JSON and Markdown, so people and different AI tools read the same records. Every save preserves the previous deck, and two separate review boards make sure approving an idea is never mistaken for approving the finished artwork. Each decision is tied to a fingerprint of the file it approved, so a changed file is caught automatically.

I also created the **visual design for the whole course**: one slide system, two families of custom icons, cinematic lesson artwork made with AI image generation, and writing rules that keep headlines memorable and instructions clear.
